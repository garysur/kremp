Executive Summary

The staging theme is materially faster than the original baseline. The biggest gains are from reducing third-party/app work during initial render, lowering JavaScript blocking time, cutting request count, and reducing page weight. Product mobile still has meaningful remaining opportunity because it is heavily affected by Shopify/app checkout scripts.

32.0 to 48.8 Average mobile Lighthouse score, +16.8 points
80.8 to 89.2 Average desktop Lighthouse score, +8.4 points
1.69s less Average mobile total blocking time
1.7MB less Average tested page weight

Key Takeaways

  • Mobile started in the low 30s on the tested pages and is now averaging just under 49 on staging.
  • Desktop is now averaging just over 89, with Product, About, Alabama, and Birthday Collection testing at 90.
  • The biggest technical win is lower blocking time: average mobile TBT fell from 2,325ms to 637ms.
  • Page weight and request count dropped across the tested set, which is important for both mobile and desktop.

How to Read the Numbers

  • Score is the Lighthouse performance score out of 100.
  • LCP tracks when the main visible content appears.
  • TBT tracks JavaScript blocking time and is the biggest improvement so far.
  • KB and requests show how much lighter the page became.
Testing note: Scores vary per run because Shopify apps, payment scripts, and third-party services respond differently each time. The report uses saved Lighthouse runs from the same test day and page set. PageSpeed Insights should be run on both mobile and desktop for live and staging URLs.

What Changed and What It Moved

Attribution is grouped by optimization batch. Lighthouse cannot perfectly isolate every individual line because Shopify apps and third-party scripts overlap, so these are batch-level readouts tied to the changes made in each pass.

Batch 1

Theme Loading Optimization

Deferred third-party loaders, reduced render-blocking stylesheets, added LCP image priority hints, scoped delivery scripts, and lazy-loaded Sur Spotlight content.

Average score +8.2. Mobile average +11.6. TBT improved 724ms. Transfer reduced 1,281KB.

Batch 2

Support App Delay

Reamaze and Alia app embed loading was replaced on staging with equivalent delayed loaders after page load or first interaction.

Average score +3.0. Mobile average +6.0. TBT improved 185ms. Transfer reduced 539KB.

Batch 3

CSS and Product Stability

Flatpickr and animation CSS were made non-blocking. Product layout space was reserved. Delivery date and zip attributes were synced before add-to-cart.

Average score +1.4. Desktop average +3.6. LCP improved 1,112ms. Product desktop reached 90.

Current Status and Remaining Opportunity

The staging theme has made meaningful progress while keeping live untouched. The remaining large gains are tied to higher-risk areas: Shopify accelerated checkout scripts, Upcart timing, BSS product options, Judge.me, jQuery-dependent inline scripts, duplicate icon/font assets, and app CSS.

The recommended path from here is controlled staging experiments: one change at a time, verify product selection, delivery date, add-to-cart, Upcart, checkout entry, and then run mobile and desktop PageSpeed tests before keeping or reverting the change.
